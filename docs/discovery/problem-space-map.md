# Problem-Space Map — High-Value, Project-Based Businesses

**Source documents:** all files in `docs/discovery/` (interview note, hypotheses, priority, interview guide, evidence matrix, segment hypotheses).
**Status: PRELIMINARY** — no area below is a confirmed problem. The only confirmed problem is that administrative recording errors have occurred in one interviewed business; the interview does not attribute them to any specific area.

**Confirmed context (one landscape architect / plant business only):**
- Project value can reach hundreds of millions of rupiah per project.
- Administration is recorded mostly manually.
- Administrative recording errors have occurred.
