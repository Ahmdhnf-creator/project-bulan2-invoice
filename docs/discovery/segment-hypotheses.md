# Segment Hypotheses — Preliminary

**Source documents:** `landscape-interview.md`, `problem-hypotheses.md`, `hypothesis-priority.md`, `interview-guide.md`, `evidence-matrix.md`
**Status: PRELIMINARY** — every segment conclusion below is a hypothesis. Only one business (landscape) has been interviewed; no segment is claimed to have the problem except that single interviewed business, and only for the facts confirmed there.

**Shared problem hypothesis under test (unvalidated):** high-value, project-based businesses with mostly manual administration may experience recording errors whose impact grows with project value (H1–H3).

## Segment 1: Landscape / garden businesses

**Currently known (confirmed, but only for ONE business — the interviewed father-in-law):**
- Landscape architect running a landscape & plant business.
- Project value can reach hundreds of millions of rupiah per project.
- Administration is mostly manual.
- Administrative recording errors have occurred.

**Still unknown:** everything listed in the interview note (project count, pricing, record types, manual media used, who records, error types/frequency/amounts, correction process) — plus whether any of the confirmed facts generalize to other businesses in this segment.

**Why relevant to the problem hypothesis:** H1–H3 were derived from this segment's single interview. The combination of high project value + manual recording + confirmed errors is exactly what the hypotheses describe — but it is one data point, not a segment pattern.

**Evidence needed:** additional interviews in this segment; error samples, amounts, and frequency; confirmation that manual recording is typical (per the interview guide's core questions).

**Accessibility:** one contact accessible (family relationship). No other contacts identified yet.
